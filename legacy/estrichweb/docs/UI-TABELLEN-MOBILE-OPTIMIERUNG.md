# UI- und Tabellenoptimierung

## Änderungen
- Helles professionelles UI erzwungen.
- Icon-Kontraste korrigiert: schwarze/unklare Symbole werden in Buttons korrekt weiß bzw. akzentfarben dargestellt.
- Button-Hover/Active-Animationen vereinheitlicht.
- Header- und Action-Positionierung optimiert.
- Generische Tabellen zeigen keine langen IDs mehr als Hauptspalte.
- IDs werden, wenn technisch vorhanden, als „verknüpft“ statt langer Hash angezeigt.
- Alle generischen Tabellen erhalten auf Handy eine Kartenansicht.
- Auftragssuche und Baustellenansicht erhalten mobile Karten statt unlesbarer Tabellen.
- Status-/Prioritätswerte werden deutsch angezeigt.

## Deployment
Auf STRATO mindestens /public ersetzen.
Für Quellstand zusätzlich /frontend-angular-source und /docs ersetzen.
