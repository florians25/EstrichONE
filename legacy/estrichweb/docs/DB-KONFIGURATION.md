# Datenbank-Konfiguration

Die produktive Konfiguration liegt in:

```text
/api/config/local.php
```

Diese Datei enthält vertrauliche Zugangsdaten und ist per `.htaccess` gegen öffentlichen Zugriff geschützt. Trotzdem darf sie nicht öffentlich geteilt oder in GitHub hochgeladen werden.

Der Installer kann die Datei neu erzeugen.
