# Tastaturkürzel

## Überall

| Tasten | Wirkung |
|---|---|
| <kbd>Strg</kbd> + <kbd>Enter</kbd> | Formular bzw. Dialog speichern (Tagesbericht, Notiz, Telefon-Schnellerfassung, Helpdesk-Antwort) |
| <kbd>Esc</kbd> | Dialog oder Auswahlliste schließen |
| <kbd>Enter</kbd> im Suchfeld | Alle Treffer in der Bauaktenliste zeigen |
| <kbd>Strg</kbd> + Klick auf einen Link | Seite in neuem Tab öffnen |
| <kbd>Tab</kbd> / <kbd>Umschalt</kbd> + <kbd>Tab</kbd> | Zum nächsten / vorherigen Feld |

## Vorschau und Großansicht

| Tasten | Wirkung |
|---|---|
| <kbd>←</kbd> / <kbd>→</kbd> | Vorheriges / nächstes Foto bzw. Dokument |
| <kbd>Esc</kbd> | Vorschau schließen |

## Helpdesk

| Tasten | Wirkung |
|---|---|
| <kbd>Strg</kbd> + <kbd>V</kbd> im Antwortfeld | Bildschirmfoto aus der Zwischenablage anhängen |
| <kbd>Strg</kbd> + <kbd>Enter</kbd> | Antwort senden |

## Disponenten-Cockpit

| Tasten | Wirkung |
|---|---|
| <kbd>?</kbd> | Hilfe zur Bedienung öffnen |
| <kbd>Enter</kbd> | Markierten Einsatz bearbeiten |
| <kbd>Leertaste</kbd> | Einsatz zur Auswahl hinzufügen / entfernen |
| <kbd>Umschalt</kbd> + <kbd>F10</kbd> | Kontextmenü |
| <kbd>Alt</kbd> + <kbd>←</kbd> / <kbd>→</kbd> | Auswahl einen Tag früher / später |
| <kbd>N</kbd> | Auswahl auf den nächsten freien Tag |
| <kbd>Entf</kbd> | Auswahl entfernen |
| <kbd>Esc</kbd> | Auswahl aufheben, Ziehen abbrechen |
| <kbd>Strg</kbd> + <kbd>Z</kbd> / <kbd>Strg</kbd> + <kbd>Y</kbd> | Rückgängig / Wiederholen |
| <kbd>T</kbd> | Zu heute springen |
| <kbd>W</kbd> | Wochenende ein- / ausblenden |
| <kbd>Bild ↑</kbd> / <kbd>Bild ↓</kbd> | Vorheriger / nächster Zeitraum |
| <kbd>Strg</kbd> + Ziehen | Einsatz kopieren statt verschieben |
| <kbd>Strg</kbd> + Klick | Mehrfachauswahl |

In Menüs des Cockpits bewegen Sie sich mit <kbd>↑</kbd> und <kbd>↓</kbd>, öffnen mit <kbd>Enter</kbd>, <kbd>Leertaste</kbd>
oder <kbd>→</kbd> und schließen mit <kbd>Esc</kbd> oder <kbd>←</kbd>. In der Kolonnenplanung öffnen <kbd>Enter</kbd> oder
<kbd>Leertaste</kbd> den markierten Einsatz.
