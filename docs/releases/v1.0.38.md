# EstrichONE 1.0.38



## Apps

- **Einplanen vom Handy:** Planer planen eine Baustelle direkt aus der Bauakte oder aus der Baustellenliste ein. Tag, Kolonne mit Auslastung, Tätigkeit und auf Wunsch die Uhrzeit stehen auf einem Blatt, Konflikte werden sofort geprüft. Der nächste Einsatz lässt sich aus der Bauakte verschieben.
- **Disposition:** „Baustelle zuweisen“ nutzt dasselbe kompakte Blatt, Kolonne und Tag sind vorbelegt.
- **Bauakte aufgeräumt:** Beschreibung und Hinweise stehen direkt nach Leistung und Kennwerten. Der Abschnitt „Ablauf“ entfällt. Erstbegehung, CM-Messung und Abnahme erfassen Sie weiter über „Erfassen“.
- **Stand auf dem Gerät als Symbol:** Ob eine Bauakte ohne Netz verfügbar ist, zeigt ein kleines Symbol oben in der Leiste. Ein Tippen nennt die Einzelheiten.

## Server aktualisieren

Bestehende Installation (ab 0.1.0 legt der Installer das Skript an):

```bash
sudo /opt/estrichone/update.sh            # neueste Version
sudo /opt/estrichone/update.sh 1.0.38  # genau diese Version
```

Das Skript kündigt das Update allen Benutzern eine Minute vorher an, meldet alle ab, sichert, aktualisiert, wartet auf
alle Dienste und gibt nach weiteren 30 Sekunden frei (mindestens 2,5 Minuten, deploy/README.md „Update-Ablauf“); es
meldet Erfolg oder Fehler. Ältere Installationen
einmalig mit dem Installer-Befehl unten aktualisieren.

## Server neu installieren

```bash
curl -fsSL https://raw.githubusercontent.com/florians25/EstrichONE/main/install.sh | sudo bash -s -- --version 1.0.38
```

Gleichwertig mit vorhandenem Docker:

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:1.0.38
```

## Archivserver und Backup-Ziel (weitere Rechner)

```bash
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.38 archiv
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.38 backup-ziel
```

Aktualisieren: denselben Befehl mit der neuen Version erneut ausführen. Koppeln in EstrichONE unter System → Archiv
bzw. System → Backup-Ziele.
