## Neu seit Vorabversion 7

**Bauakte (Web)**
- Neuer, kompakter Kopf; Übersicht als lückenloses Raster; Reiter „Kontakte“ direkt nach der Übersicht (Beteiligte mit
  Rolle, Anruf/Mail, Schnellerfassung, Dublettenprüfung); „Letzte Aktivitäten“ als Fenster über „Aktionen“;
  „Mir zuweisen“.
- Dokumente und Fotos/Videos: Liste im Vordergrund, Hochladen und Vorschau in Dialogen (große PDF-Vorschau), Kerndaten
  der Akte im Dialogkopf; Dokumentenbaum Kunde → Bauakte → Dokumentart (zentral und in der Akte).
- Erstbegehung mit freien Notizen; direkt aus dem Anlage-Assistenten startbar.
- **Digitales Abnahmeprotokoll** mit Unterschriften, optionalem Freigabelink per E-Mail an den Kunden, automatischem
  PDF in der Akte (archiviert) und automatischem Abschluss der Bauakte.
- Status automatisch von „Geplant“ auf „In Arbeit“ (Auslöser einstellbar).

**PDF und Firma**
- Alle Ausdrucke als Server-PDF; Briefe und Bestellscheine nach DIN 5008; Firmenlogo (Firmendaten) plus
  EstrichONE-Logo in der Fußzeile; erzeugte PDFs werden automatisch in der Bauakte abgelegt (mit Fassungen).
- Zugangsbrief für neue Benutzer mit Einmalpasswort (Passwortwechsel bei der ersten Anmeldung), auf Wunsch per E-Mail.

**Planung, Personal, Helpdesk**
- **Wer fährt wohin** als Dispatching von Kolonnen auf Baustellen je Tag (Ziehen/Auswahl, mehrere Kolonnen je
  Baustelle, Warnung bei Doppelbelegung, PDF nach Kolonnen).
- Teamplaner nach Uhrzeiten, Terminkalender (Tag/Woche/Monat/Agenda), Personalstamm mit Mitarbeiterakte,
  Urlaubsanträge mit Genehmigung und Resturlaub, Urlaubsplan, Krankmeldungen, Fristen.
- IT-Tickets können alle Benutzer im Web anlegen (mit Screenshot per Strg+V), Verlauf je Ticket.

**Einstellungen**
- „Systemeinstellungen“ mit Reitern (Sitzung, Karte, Nummernkreise, Bauakte, Freigaben, Benachrichtigungen,
  Darstellung, PDF, Module); Materialmodul abschaltbar.

**iOS**
- Startseite als Dashboard (iPad zweispaltig), „Meine Einsätze heute“ als Karten, „Wer fährt wohin“ nach Kolonnen,
  Abnahmeprotokoll erfassen und anzeigen, Statuswechsel nach den gemeinsamen Regeln, **Demomodus** für die
  App-Prüfung, korrekte Anzeige von Dokumenten/Bildern (Vorschau, Vollbild mit Zoom, WebP/HEIC/Office).

## Server aktualisieren

```bash
sudo /opt/estrichone/update.sh 0.1.0-preview.8
```

Installationen vor Vorabversion 7 einmalig mit dem Installer:

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:0.1.0-preview.8
```

Archivserver/Backup-Ziel: `… estrichone-installer:0.1.0-preview.8 archiv` bzw. `… backup-ziel` (siehe Vorabversion 7).
Hosting-Konsole: `ghcr.io/florians25/estrichone-hosting:0.1.0-preview.8 install`.

## Bekannte Grenzen

- iOS: UI-Tests laufen nicht mehr in der CI (lokal in Xcode startbar); Demomodus erzeugt kein Abnahme-PDF.
- Fahrzeuge einer Kolonne ergeben sich aus den an Mitglieder ausgegebenen Fahrzeugen (keine direkte Zuordnung).
- Archiv: Schutz durch die Software (Schreibschutz + Hash-Kette), kein physischer WORM-Speicher.
- Windows-App wird nicht weiterentwickelt.
