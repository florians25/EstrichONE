# EstrichONE 0.1.1

Fehlerbehebung für 0.1.0.

## Behoben
- **Web-Anmeldung:** Nach erfolgreicher Anmeldung wurde die Sitzung sofort beendet und die Anmeldung hing in einer
  Schleife, wenn EstrichONE direkt per unverschlüsseltem HTTP (z. B. `http://<IP>:8080`) aufgerufen wurde oder die
  Uhr von Server bzw. Gerät falsch ging. Sitzungs-Cookies sind jetzt robust (Max-Age; `Secure` bleibt bei HTTPS und
  hinter Nginx Proxy Manager erhalten), CSRF-Schutz und SameSite unverändert.
- Statt der Schleife erscheint eine klare Meldung (unverschlüsselter Aufruf, blockierte Cookies, Uhrzeit).
- Administratoren sehen einen Hinweis, wenn die konfigurierte Adresse (`ESTRICHONE_DOMAIN`) von der aufgerufenen
  abweicht – mit passendem Installer-Aufruf.
- Neuer automatischer Test mit Nginx-Proxy-Manager-Konfiguration vor EstrichONE (Einrichtung, Abmelden, erneute Anmeldung).

## Aktualisieren
`sudo /opt/estrichone/update.sh 0.1.1`

EstrichONE immer über die HTTPS-Adresse aufrufen (z. B. `https://leisuleis.estrichone.de`), nicht über `http://<IP>:8080`.
