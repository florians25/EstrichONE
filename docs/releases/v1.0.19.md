# EstrichONE 1.0.19

## Neu

- Web wieder im SAP-Standard (Horizon): Seitenkopf, Abschnitte, Leerzustände, Status und Kurzmeldungen wie ab Werk; der Seitenkopf reicht bis an den rechten Rand.
- Microsoft Teams: „Chat in Teams“ bei Personen (Bauakten-Team, Mitarbeiter) und im Teams-Menü der Kopfzeile, „Chat mit dem ganzen Bauakten-Team“, Nachricht in Teams posten.
- Teams-Kanäle archivieren, wiederherstellen und löschen, Gruppenchats löschen (neues Recht „teams.delete“, Bestätigung mit Bauaktennummer). Beim Abschließen einer Bauakte wird der Kanal auf Wunsch archiviert.
- Einstellungen › Microsoft Teams › Umstellung: Überblick über Konten und Bauakten, alle offenen Bauakten in einem Hintergrundlauf mit Teams verknüpfen; der Verbindungstest zeigt fehlende optionale Berechtigungen. Einmaliger Hinweis „Ab sofort chatten wir in Teams“.
- Der Helpdesk bleibt ohne Teams-Bezug.
- Update-Ablauf: Abschlussphase 30 Sekunden statt einer Minute (zusammen mindestens 2,5 Minuten).

## Apps

- „Neuer Chat in Teams“ und „Chat mit dem Team in Teams“ öffnen direkt die Microsoft-Teams-App; ist sie nicht installiert, gibt es einen Hinweis zum Installieren.
- Einmaliger Hinweis „Ab sofort chatten wir in Teams“.

## Server aktualisieren

Bestehende Installation (ab 0.1.0 legt der Installer das Skript an):

```bash
sudo /opt/estrichone/update.sh            # neueste Version
sudo /opt/estrichone/update.sh 1.0.19  # genau diese Version
```

Das Skript kündigt das Update allen Benutzern eine Minute vorher an, meldet alle ab, sichert, aktualisiert, wartet auf
alle Dienste und gibt nach weiteren 30 Sekunden frei (mindestens 2,5 Minuten, deploy/README.md „Update-Ablauf“); es
meldet Erfolg oder Fehler. Ältere Installationen
einmalig mit dem Installer-Befehl unten aktualisieren.

## Server neu installieren

```bash
curl -fsSL https://raw.githubusercontent.com/florians25/EstrichONE/main/install.sh | sudo bash -s -- --version 1.0.19
```

Gleichwertig mit vorhandenem Docker:

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:1.0.19
```

## Archivserver und Backup-Ziel (weitere Rechner)

```bash
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.19 archiv
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.19 backup-ziel
```

Aktualisieren: denselben Befehl mit der neuen Version erneut ausführen. Koppeln in EstrichONE unter System → Archiv
bzw. System → Backup-Ziele.
