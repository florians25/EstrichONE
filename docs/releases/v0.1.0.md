# EstrichONE 0.1.0

Erste reguläre Version von EstrichONE – der kostenlosen, selbst gehosteten Suite für Estrichbetriebe
(Ersatz für „Estrich Web“). Enthält alles aus den Vorabversionen bis 0.1.0-preview.24.

## Sicherheitsupdate
Diese Version enthält alle Sicherheitskorrekturen aus 0.1.0-preview.24 (u. a. Rechteausweitung behoben,
Zwei-Faktor-Anmeldung, gehärtete Container und Proxy, Anfragelimits, aktualisierte Abhängigkeiten).
Öffentlich erreichbare Server bitte zeitnah aktualisieren.

## Was drin ist
- **Web (OpenUI5, alle Themes, PWA):** Bauakte mit Dokumenten, Fotos und Videos samt Vorschau, DMS mit Versionen und
  Genehmigungen, Erstbegehung und Abnahme mit Unterschrift, PDF-Berichte nach DIN 5008, Kunden und Kontakte mit
  Dublettenprüfung, Disponenten-Cockpit und Kolonnenplanung, Kalender, Personal und Urlaub, Material und Bestellungen,
  Helpdesk, Chat, Benachrichtigungen, Stammdaten, Rechteverwaltung, Einstellungen.
- **iOS (iPhone und iPad):** Heute-Seite, Bauakte offline, Fotos/Scans/Videos, Erstbegehung und Abnahme,
  Wer fährt wohin mit Schnelldisposition und Plan-Freigabe, Kunden und Kontakte, Chat mit Diktat, Helpdesk,
  Pushnachrichten, Face ID, „Nur Ansicht“ ohne Server, Demo-Modus für die App-Prüfung.
- **Android:** Basis-App. **Windows-App:** unverändert, wird nicht weiterentwickelt.
- **Server:** ASP.NET Core + PostgreSQL in Docker, Installation und Update mit einem Befehl, Modus Proxy
  (z. B. Nginx Proxy Manager) oder direkt mit HTTPS.
- **Datensicherung:** tägliche Vollsicherung, Backup-Ziel auf anderer Hardware (auch zuhause hinter NAT),
  Wiederherstellen per Knopf, Neuinstallation aus der Sicherung mit Notfallblatt, Warnungen bei Ausfall.
- **Archivserver** für 10 Jahre (revisionssicher), Zusatzserver per Knopf vom Hauptserver aktualisierbar.
- **Hosting-Konsole** für mehrere Betriebe: Installation mit einem Befehl, Mandanten-Assistent, Updates mit Rückfall.

## Neu installieren
```bash
sudo mkdir -p /opt/estrichone && sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:0.1.0
```
Hinter Nginx Proxy Manager zusätzlich `-e ESTRICHONE_MODE=proxy` angeben (HTTP auf Port 8181).

Hosting-Konsole:
```bash
curl -fsSL https://raw.githubusercontent.com/florians25/EstrichONE/main/hosting/install.sh | sudo bash
```

## Von einer Vorabversion aktualisieren
`sudo /opt/estrichone/update.sh 0.1.0`

Backup-Ziele und Archivserver danach im Web unter Backup-Ziele bzw. Archiv per „Aktualisieren“ nachziehen.

## Empfohlen nach dem Update
1. Konto → Anmeldung und Sicherheit: Zwei-Faktor einrichten, Wiederherstellungscodes sichern.
2. System → Firmendaten → Anmeldung: „Pflicht für Administratoren“ einschalten.
3. Automatische Sicherheitsupdates: `sudo /opt/estrichone/update.sh --automatik sicherheit`
4. Checkliste „Öffentlich betreiben“ in docs/sicherheit.md (Firewall, Nginx Proxy Manager).
5. Notfallblatt im Backup Center ausdrucken und sicher aufbewahren.

## Bekannte Grenzen
- Windows-App ohne Zwei-Faktor-Schritt; Android als Basis-App.
- Echte Pushnachrichten (APNs) und Diktat lassen sich nur auf echten Geräten prüfen, nicht im Simulator.
- Einzelne Bauakten lassen sich nicht separat aus der Sicherung zurückspielen (ganzes System oder einzelne Dateien).
