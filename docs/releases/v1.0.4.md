# EstrichONE 1.0.4

## Neu

- Hinweise zu ausgefallenen Servern (Backup-Server rot, Archivserver gelb) sehen nur noch Administratoren
  (Recht „Einstellungen verwalten“ oder „Sicherung verwalten“) – in Web, iOS und Android. Andere Benutzer werden
  damit nicht mehr verunsichert. Administratoren bekommen wie bisher zusätzlich Push und Postfach-Meldung.
- Der Text richtet sich jetzt an Administratoren („… unter System → Sicherung prüfen“).

## Update

```bash
sudo /opt/estrichone/update.sh 1.0.4
```
