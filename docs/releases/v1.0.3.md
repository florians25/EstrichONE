# EstrichONE 1.0.3

## Neu

- Große Bildschirme: Schrift, Bedienelemente und Fenster werden automatisch größer – ab 2200 px Breite 112 %,
  ab 2800 px 125 %, breite Curved-/Ultrawide-Monitore (z. B. 3440×1440, 5120×1440) 125 %, 4K und 5K2K 150 %.
- Einstellungen → „Schrift- und Fenstergröße“: Automatisch, 100 %, 112 %, 125 %, 150 % oder 175 %, sofort wirksam
  und je Browser gespeichert.

## Update

```bash
sudo /opt/estrichone/update.sh 1.0.3
```
