# EstrichONE 1.0.14

## Neu

- Helpdesk als Service-Desk der IT: Arbeitsplatz mit Kennzahlen, gespeicherten Ansichten (Meine, Nicht zugewiesen, Überfällig, Wartet auf Rückmeldung …), Volltextsuche, sortierbarer Liste und Sammelbearbeitung.
- SLA-Ziele für erste Antwort und Lösung je Priorität in Geschäftszeit (mit Feiertagen); die Uhr steht, solange eine Rückfrage beim Melder liegt.
- Gruppen, Unterkategorien und automatische Zuweisung nach Regeln.
- Ticket mit Reitern für Verlauf, Melder & Geräte, Verknüpfungen, Zeit und Prüfpfad; Textbausteine, Erwähnungen, Zusammenführen, Verknüpfen, Zeiterfassung.
- Wissensdatenbank mit Vorschlägen schon beim Melden; Bewertung durch den Melder.
- Neue Berechtigung „Helpdesk verwalten“ für SLA, Gruppen und Regeln.
- Installation mit einem Befehl (`install.sh`): prüft Server, Docker, Ports, DNS und Firewall, installiert Docker bei Bedarf und repariert beim erneuten Aufruf.
- Hosting-Konsole: Rolle „nur lesen“, Apps und Module je Instanz, neueste Version mit Versionshinweisen, automatische Rücknahme, wenn eine Instanz nach dem Update nicht bereit wird, strengere Passwortregeln.

## Apps

- Problem melden mit Unterkategorie, Priorität, Fotos und abwählbarer Diagnose; Anleitungen werden vorgeschlagen.
- Verlauf als Unterhaltung, Bewertung nach der Lösung.
- IT-Bearbeiter sehen ihre Tickets, können übernehmen, Status setzen und lösen.

## Android

- Meldungen werden zuerst auf dem Gerät gespeichert und auch offline gesendet.

## Server aktualisieren

Bestehende Installation (ab 0.1.0 legt der Installer das Skript an):

```bash
sudo /opt/estrichone/update.sh            # neueste Version
sudo /opt/estrichone/update.sh 1.0.14  # genau diese Version
```

Das Skript sichert vorher, aktualisiert, wartet auf alle Dienste und meldet Erfolg oder Fehler. Ältere Installationen
einmalig mit dem Installer-Befehl unten aktualisieren.

## Hosting-Konsole installieren

```bash
curl -fsSL https://raw.githubusercontent.com/florians25/EstrichONE/main/install.sh | sudo bash -s -- konsole
```

## Server neu installieren

```bash
curl -fsSL https://raw.githubusercontent.com/florians25/EstrichONE/main/install.sh | sudo bash -s -- --version 1.0.14
```

Gleichwertig mit vorhandenem Docker:

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:1.0.14
```

## Archivserver und Backup-Ziel (weitere Rechner)

```bash
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.14 archiv
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.14 backup-ziel
```

Aktualisieren: denselben Befehl mit der neuen Version erneut ausführen. Koppeln in EstrichONE unter System → Archiv
bzw. System → Backup-Ziele.
