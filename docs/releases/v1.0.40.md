# EstrichONE 1.0.40



## Neu

- **Lexware Office, Änderungen abgleichen:** Bei verknüpften Kunden mit eingeschaltetem Abgleich erkennt EstrichONE Änderungen auf beiden Seiten und überträgt sie. Wurde derselbe Wert auf beiden Seiten geändert, erscheint er unter „Abweichungen“ und Sie entscheiden, welcher Stand gilt. Die Richtung des Abgleichs legen Sie in der Verwaltung fest. EstrichONE löscht nie einen Kontakt in Lexware Office.
- **Lexware Office, Hinweis beim Anlegen:** Legen Sie einen Kunden an, der in Lexware Office bereits vorhanden ist, meldet EstrichONE „Achtung: Dieser Kunde ist bereits in Lexware Office vorhanden.“ Sie übernehmen den Kontakt mit einem Klick oder legen bewusst neu an.
- **Lexware Office, automatische Anlage:** Gibt es in Lexware Office keinen ähnlichen Kontakt, legt EstrichONE den neuen Kunden dort automatisch an, sofern der Abgleich für ihn eingeschaltet ist. Die Funktion schalten Sie in der Verwaltung ein. Bestehende Kunden werden nur nach Vorschau und Bestätigung angelegt.
- **Lexware Office in der Bauakte:** Ist der Kunde verknüpft, zeigt die Übersicht der Bauakte den Kontakt aus Lexware Office, den Stand des Abgleichs und eine Zusammenfassung der Belege.
- **Belege als PDF:** Rechnungen und Angebote öffnen Sie in der Vorschau und laden sie herunter, soweit Lexware Office das Dokument bereitstellt.
- **Hinweise und Zugang:** Die Felder „Hinweise und Behinderungen“ und „Zugang / Besonderheiten“ sind zu einem Feld zusammengeführt. Vorhandene Einträge aus beiden Feldern bleiben erhalten und stehen jetzt gemeinsam in diesem Feld.

## Apps

- **Bauakte:** Die Apps zeigen einen Block „Hinweise und Zugang“ statt zwei getrennter Angaben. Ältere App-Versionen arbeiten weiter.

## Server aktualisieren

Bestehende Installation (ab 0.1.0 legt der Installer das Skript an):

```bash
sudo /opt/estrichone/update.sh            # neueste Version
sudo /opt/estrichone/update.sh 1.0.40  # genau diese Version
```

Das Skript kündigt das Update allen Benutzern eine Minute vorher an, meldet alle ab, sichert, aktualisiert, wartet auf
alle Dienste und gibt nach weiteren 30 Sekunden frei (mindestens 2,5 Minuten, deploy/README.md „Update-Ablauf“); es
meldet Erfolg oder Fehler. Ältere Installationen
einmalig mit dem Installer-Befehl unten aktualisieren.

## Server neu installieren

```bash
curl -fsSL https://raw.githubusercontent.com/florians25/EstrichONE/main/install.sh | sudo bash -s -- --version 1.0.40
```

Gleichwertig mit vorhandenem Docker:

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:1.0.40
```

## Archivserver und Backup-Ziel (weitere Rechner)

```bash
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.40 archiv
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.40 backup-ziel
```

Aktualisieren: denselben Befehl mit der neuen Version erneut ausführen. Koppeln in EstrichONE unter System → Archiv
bzw. System → Backup-Ziele.
