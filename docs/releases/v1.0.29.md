# EstrichONE 1.0.29


## Apps

- **Schnellaktionen am App-Symbol** (lange drücken): „Foto zur Baustelle“, „Bautagebuch“, „Baustelle suchen“, auch als Kurzbefehl, per Siri und über die Aktionstaste.
- **Auslösen mit der Lautstärketaste** bzw. Kamerataste (iPhone ab iOS 18), mit Handschuhen sicherer.
- **Ohne Netz** zeigt die Kamera, dass die Fotos sicher auf dem Gerät bleiben.
- **Fotos brauchen rund 60 % weniger Platz** und Datenvolumen; Aufnahmezeit und Ort bleiben erhalten.
- **Videos im Format H.264**: im Browser überall abspielbar.
- **Speicheranzeige** unter Mehr › Gerät, Server und App mit „Cache leeren“, noch nicht hochgeladene Fotos bleiben immer erhalten.
- Übertragene Fotos und Videos bleiben nur noch 2 Tage als Sicherheitskopie auf dem Gerät.

## Server aktualisieren

Bestehende Installation (ab 0.1.0 legt der Installer das Skript an):

```bash
sudo /opt/estrichone/update.sh            # neueste Version
sudo /opt/estrichone/update.sh 1.0.29  # genau diese Version
```

Das Skript kündigt das Update allen Benutzern eine Minute vorher an, meldet alle ab, sichert, aktualisiert, wartet auf
alle Dienste und gibt nach weiteren 30 Sekunden frei (mindestens 2,5 Minuten, deploy/README.md „Update-Ablauf“); es
meldet Erfolg oder Fehler. Ältere Installationen
einmalig mit dem Installer-Befehl unten aktualisieren.

## Server neu installieren

```bash
curl -fsSL https://raw.githubusercontent.com/florians25/EstrichONE/main/install.sh | sudo bash -s -- --version 1.0.29
```

Gleichwertig mit vorhandenem Docker:

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:1.0.29
```

## Archivserver und Backup-Ziel (weitere Rechner)

```bash
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.29 archiv
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.29 backup-ziel
```

Aktualisieren: denselben Befehl mit der neuen Version erneut ausführen. Koppeln in EstrichONE unter System → Archiv
bzw. System → Backup-Ziele.
