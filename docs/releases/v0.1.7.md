# EstrichONE 0.1.7

Bugfix-Version zur Bedienung der Seitennavigation.

## Web
- Seitennavigation bleibt bei Laptops mit 125/150 % Skalierung ausgeklappt (wie bis 0.1.5); nur Tablets hochkant zeigen
  die Symbolleiste.
- Ladeanimation, wenn ein Seitenwechsel länger als 0,3 s dauert.
- Stammdaten: funktionslose Links unter „Weitere Stammdaten“ entfernt (Ziele weiter über die Seitennavigation).

## Aktualisieren
`sudo /opt/estrichone/update.sh 0.1.7`
