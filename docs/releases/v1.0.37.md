# EstrichONE 1.0.37



## Apps

Die Apps für iPhone, iPad und Android sind für den Einsatz auf der Baustelle und beim Kunden erweitert.

- **Offline verfügbar:** Bauakten der Einsätze von heute und der nächsten Tage werden vorab geladen, einschließlich Dokumenten und der neuesten Fotos. Die Bauakte zeigt „Auf dem Gerät verfügbar“. Auf dem iPhone lassen sich weitere Bauakten über „Auf dem Gerät bereithalten“ dazunehmen.
- **Übertragungsstand sichtbar:** Eine Zeile zeigt, was noch auf die Übertragung wartet, zum Beispiel „3 Fotos warten auf Übertragung“. Fehlgeschlagene Uploads werden verständlich erklärt und lassen sich mit „Erneut senden“ wiederholen. Auf Android werden Fotos und Einträge auch übertragen, wenn die App geschlossen wurde.
- **Serienfotos:** Art (Vorher, Einbau, Nachher, Mangel) und Raum gelten für die ganze Serie und stehen in der Beschriftung. Der Standort kann mitgespeichert werden und ist in der Kamera abschaltbar.
- **Diktieren:** in Bautagebuch, Mangel, Notiz, CM-Messung, Erstbegehung und Abnahme.
- **Entwürfe:** Eingaben werden laufend gesichert und nach Abbruch oder Neustart wieder angeboten.
- **Abnahme beim Kunden:** geführter Ablauf mit Zusammenfassung und Pflichtprüfung vor dem Abschluss. Der Kunde unterschreibt direkt auf dem Gerät. Das Protokoll lässt sich als PDF ansehen, teilen und per E-Mail an den Kunden senden.
- **Kundenansicht:** Protokoll, Unterschrift und Fotos im Vollbild ohne interne Angaben.
- **Angekommen und Fertig:** Am Einsatz halten Sie die Uhrzeit fest. Sie wird für das Bautagebuch übernommen.
- **Schnellzugriffe:** Foto, Bautagebuch und Mangel direkt am App-Symbol, mit Ziel in der Bauakte des laufenden Einsatzes. Auf Android bietet langes Drücken auf Einsätze und Baustellen Route, Foto, Tagebuch und Mangel.
- **Bedienung im Freien:** Der Bildschirm bleibt während der Erfassung an. Schaltflächen in den Erfassungsdialogen sind größer, Kontraste wurden angehoben.

## Server aktualisieren

Bestehende Installation (ab 0.1.0 legt der Installer das Skript an):

```bash
sudo /opt/estrichone/update.sh            # neueste Version
sudo /opt/estrichone/update.sh 1.0.37  # genau diese Version
```

Das Skript kündigt das Update allen Benutzern eine Minute vorher an, meldet alle ab, sichert, aktualisiert, wartet auf
alle Dienste und gibt nach weiteren 30 Sekunden frei (mindestens 2,5 Minuten, deploy/README.md „Update-Ablauf“); es
meldet Erfolg oder Fehler. Ältere Installationen
einmalig mit dem Installer-Befehl unten aktualisieren.

## Server neu installieren

```bash
curl -fsSL https://raw.githubusercontent.com/florians25/EstrichONE/main/install.sh | sudo bash -s -- --version 1.0.37
```

Gleichwertig mit vorhandenem Docker:

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:1.0.37
```

## Archivserver und Backup-Ziel (weitere Rechner)

```bash
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.37 archiv
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.37 backup-ziel
```

Aktualisieren: denselben Befehl mit der neuen Version erneut ausführen. Koppeln in EstrichONE unter System → Archiv
bzw. System → Backup-Ziele.
