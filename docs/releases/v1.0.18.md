# EstrichONE 1.0.18

## Neu

- Seitenkopf: Kopf, Kopfdaten, Reiterleiste und Inhalt auf einer Fläche ohne abgesetzte Hintergründe; schmalerer Seitenrand; beim Scrollen scheint kein Inhalt mehr um den Kopf herum durch.
- Kurzmeldungen („Gespeichert“, „Kopiert“ …) oben rechts als kleine Karten mit Symbol und Farbe je Art, gestapelt, per Klick schließbar.
- Microsoft Teams: Aktionen antworten spätestens nach rund 25 Sekunden mit verständlicher Meldung; Benutzer werden gebündelt zugeordnet; der Verbindungstest zeigt den fehlgeschlagenen Schritt; Fehler von Microsoft werden mit Schritt und Fehlercode protokolliert. Behebt den Fehler „The origin web server returned an invalid or incomplete response“ hinter Cloudflare.
- Unvollständige Antworten von Proxy/Cloudflare werden in allen Dialogen auf Deutsch erklärt.

## Apps

- Im Chat können keine Dateien, Fotos oder Videos mehr verschickt werden. Hinweis „Für Datei- und Fotoaustausch bitte Microsoft Teams verwenden.“ mit „In Teams öffnen“, wenn Teams angebunden ist. Ältere Anhänge bleiben sichtbar.

## Server aktualisieren

Bestehende Installation (ab 0.1.0 legt der Installer das Skript an):

```bash
sudo /opt/estrichone/update.sh            # neueste Version
sudo /opt/estrichone/update.sh 1.0.18  # genau diese Version
```

Das Skript kündigt das Update allen Benutzern eine Minute vorher an, meldet alle ab, sichert, aktualisiert, wartet auf
alle Dienste und gibt nach einer weiteren Minute frei (mindestens 3 Minuten, deploy/README.md „Update-Ablauf“); es
meldet Erfolg oder Fehler. Ältere Installationen
einmalig mit dem Installer-Befehl unten aktualisieren.

## Server neu installieren

```bash
curl -fsSL https://raw.githubusercontent.com/florians25/EstrichONE/main/install.sh | sudo bash -s -- --version 1.0.18
```

Gleichwertig mit vorhandenem Docker:

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:1.0.18
```

## Archivserver und Backup-Ziel (weitere Rechner)

```bash
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.18 archiv
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.18 backup-ziel
```

Aktualisieren: denselben Befehl mit der neuen Version erneut ausführen. Koppeln in EstrichONE unter System → Archiv
bzw. System → Backup-Ziele.
