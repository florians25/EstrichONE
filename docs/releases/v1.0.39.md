# EstrichONE 1.0.39



## Neu

- **Lexware Office:** EstrichONE arbeitet jetzt mit Lexware Office zusammen. Rechnungen und Angebote erstellen Sie weiterhin ausschließlich in Lexware Office. EstrichONE zeigt sie am Kunden und in der Bauakte an, mit Nummer, Datum, Betrag und Status, und führt mit einem Klick zum Beleg.
- **Rechnungen und Angebote in der Bauakte:** Im neuen Abschnitt ordnen Sie vorhandene Belege einer Bauakte zu. Nennt ein Beleg die Bauaktennummer, schlägt EstrichONE ihn vor. Der Status wird mit Lexware Office abgeglichen: Entwurf, offen, überfällig, bezahlt, storniert, bei Angeboten angenommen oder abgelehnt.
- **Kundenabgleich mit Dublettenprüfung:** Kunden verknüpfen Sie mit ihrem Kontakt in Lexware Office, legen sie dort an oder übernehmen sie von dort. Vor jedem Anlegen prüft EstrichONE in beide Richtungen auf doppelte Einträge und nennt den Grund jedes Treffers. Die Verwaltung zeigt, was verknüpft ist und was fehlt.
- **Mit Lexware Office abgleichen:** Je Kunde legen Sie fest, ob er abgeglichen wird oder nur in EstrichONE bleibt. Die Vorgabe für neue Kunden stellen Sie in der Verwaltung ein. Bestehende Kunden bleiben zunächst nur in EstrichONE.
- **Einrichtung:** Unter Verwaltung, Integrationen, Lexware Office hinterlegen Sie den API-Schlüssel und testen die Verbindung. Das Modul ist nach dem Update ausgeschaltet. Die Rechte zum Ansehen und Zuordnen von Belegen vergibt die Administration.

## Apps

- **Kunden:** Nutzt Ihr Betrieb Lexware Office, zeigt das Kunden-Formular den Schalter „Mit Lexware Office abgleichen“. Die Kundenansicht nennt den Stand.

## Server aktualisieren

Bestehende Installation (ab 0.1.0 legt der Installer das Skript an):

```bash
sudo /opt/estrichone/update.sh            # neueste Version
sudo /opt/estrichone/update.sh 1.0.39  # genau diese Version
```

Das Skript kündigt das Update allen Benutzern eine Minute vorher an, meldet alle ab, sichert, aktualisiert, wartet auf
alle Dienste und gibt nach weiteren 30 Sekunden frei (mindestens 2,5 Minuten, deploy/README.md „Update-Ablauf“); es
meldet Erfolg oder Fehler. Ältere Installationen
einmalig mit dem Installer-Befehl unten aktualisieren.

## Server neu installieren

```bash
curl -fsSL https://raw.githubusercontent.com/florians25/EstrichONE/main/install.sh | sudo bash -s -- --version 1.0.39
```

Gleichwertig mit vorhandenem Docker:

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:1.0.39
```

## Archivserver und Backup-Ziel (weitere Rechner)

```bash
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.39 archiv
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.39 backup-ziel
```

Aktualisieren: denselben Befehl mit der neuen Version erneut ausführen. Koppeln in EstrichONE unter System → Archiv
bzw. System → Backup-Ziele.
