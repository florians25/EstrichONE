# EstrichONE 1.0.10

## Verbessert

- **Anmeldung im Web neu gestaltet:** auf großen Bildschirmen zweigeteilt mit Markenfläche (Logo, Firmenname, Version)
  und Formular; auf Handy und schmalen Fenstern kompakte Karte. Ohne Werbetext.
- Passwort anzeigen/verbergen, Hinweis bei aktivierter Feststelltaste.
- „Passwort vergessen?“ mit Hinweis auf die Administration.
- Anmeldename wird nur bei „Angemeldet bleiben“ gemerkt; der Cursor steht dann direkt im Passwortfeld.
- Link zur Ersteinrichtung heißt jetzt „Einrichtung starten“.

## Update

```bash
sudo /opt/estrichone/update.sh 1.0.10
```
