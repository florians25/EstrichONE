# EstrichONE 1.0.16

## Neu

- Geordneter Update-Ablauf (mindestens 3 Minuten): 1 Minute Ankündigung mit Countdown für alle angemeldeten Benutzer, dann Abmeldung und Update-Bildschirm während des Updates, nach dem Start noch 1 Minute Abschluss, danach Freigabe. Gilt für update.sh, install.sh und die Hosting-Konsole (mit Phasenanzeige je Instanz).
- Störungs- und Update-Seite im Web mit OpenUI5, auch während der Server neu startet.
- Kunden löschen (mit Bestätigung durch die Kundennummer, eigenes Recht), Kunden mit verknüpften Daten archivieren und reaktivieren, DSGVO-Anonymisierung (nur Administrator). Archivierte Kunden lassen sich nicht neu zuordnen; die Dublettenprüfung bietet „Reaktivieren und verwenden“.
- Hinweisleisten mit Abstand zum Rand und zur Kopfzeile; Hinweiskarten auf der Startseite werden wieder angezeigt.

## Apps

- Update-Ankündigung mit Countdown und Update-Bildschirm während eines Server-Updates; offene Änderungen werden vorher übertragen.
- Kunden löschen, archivieren und reaktivieren (für Berechtigte, mit Verbindung); archivierte Kunden erscheinen nicht mehr in der Auswahl.

## Server aktualisieren

Bestehende Installation (ab 0.1.0 legt der Installer das Skript an):

```bash
sudo /opt/estrichone/update.sh            # neueste Version
sudo /opt/estrichone/update.sh 1.0.16  # genau diese Version
```

Das Skript kündigt das Update allen Benutzern eine Minute vorher an, meldet alle ab, sichert, aktualisiert, wartet auf
alle Dienste und gibt nach einer weiteren Minute frei (mindestens 3 Minuten, deploy/README.md „Update-Ablauf“); es
meldet Erfolg oder Fehler. Hinweis: Das Update auf 1.0.16 selbst läuft noch ohne die Phasen (es wird vom bisherigen update.sh eingespielt); ab dem nächsten Update gilt der neue Ablauf. Ältere Installationen
einmalig mit dem Installer-Befehl unten aktualisieren.

## Server neu installieren

```bash
curl -fsSL https://raw.githubusercontent.com/florians25/EstrichONE/main/install.sh | sudo bash -s -- --version 1.0.16
```

Gleichwertig mit vorhandenem Docker:

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:1.0.16
```

## Archivserver und Backup-Ziel (weitere Rechner)

```bash
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.16 archiv
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.16 backup-ziel
```

Aktualisieren: denselben Befehl mit der neuen Version erneut ausführen. Koppeln in EstrichONE unter System → Archiv
bzw. System → Backup-Ziele.
