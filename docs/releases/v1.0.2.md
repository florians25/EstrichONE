# EstrichONE 1.0.2


## Erste finale Version für den Produktivbetrieb

EstrichONE 1.0.2 ist die erste stabile Version für den produktiven Einsatz. Sie umfasst alles aus den Versionen 0.1.x:
Bauakten, Disposition und Kolonnenplanung, Anfragen und Telefon-Schnellerfassung, Material und Bestellungen, Chat,
Benachrichtigungen und Push, Systemhinweise und Wartung, Backup und Wiederherstellung, Archivserver, Backup-Ziel,
Hosting-Konsole sowie die Apps für iOS und Android.

## Neu gegenüber 0.1.8

- Einheitliche Versionsnummer 1.0.2 in Server, Web, iOS-App (Marketing-Version) und Android-App.
- Keine funktionalen Änderungen gegenüber 0.1.8: Update von 0.1.x ist ohne zusätzliche Schritte möglich.

## Server aktualisieren

Bestehende Installation (ab 0.1.0 legt der Installer das Skript an):

```bash
sudo /opt/estrichone/update.sh            # neueste Version
sudo /opt/estrichone/update.sh 1.0.2  # genau diese Version
```

Das Skript sichert vorher, aktualisiert, wartet auf alle Dienste und meldet Erfolg oder Fehler. Ältere Installationen
einmalig mit dem Installer-Befehl unten aktualisieren.

## Server neu installieren

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:1.0.2
```

## Archivserver und Backup-Ziel (weitere Rechner)

```bash
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.2 archiv
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.2 backup-ziel
```

Aktualisieren: denselben Befehl mit der neuen Version erneut ausführen. Koppeln in EstrichONE unter System → Archiv
bzw. System → Backup-Ziele.
