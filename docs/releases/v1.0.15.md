# EstrichONE 1.0.15

## Neu

- Navigation: eigene Gruppe „IT-Service/Helpdesk“ (Helpdesk, Problem melden, Wissensdatenbank, Helpdesk-Einstellungen).
- Gelöste Tickets werden nach 5 Tagen automatisch geschlossen (Frist einstellbar); bis dahin kann der Melder wieder öffnen.
- Neuer Status „Warten auf Support“: Antwortet der Melder auf eine Rückfrage („Warten auf Anwenderinfo“), wechselt das Ticket automatisch und die Zuständigen werden benachrichtigt.
- „Meldung aufnehmen“: Die IT legt Tickets im Namen eines Melders an (Telefon, E-Mail, vor Ort).
- Gesetzliche Feiertage je Bundesland für die SLA-Berechnung; Kennzahlen in Geschäftszeit.
- @-Erwähnung mit Vorschlägen beim Tippen; Arbeitsliste lädt seitenweise nach.
- Helpdesk-Seiten nutzen die volle Breite; Schnellaktionen auch bei kleineren Fenstern sichtbar.
- Archivserver und Backup-Ziele: Ausfall wird erst gemeldet, wenn sie länger als 3 Minuten nicht erreichbar sind (einstellbar unter Einstellungen › Benachrichtigungen).
- Hosting-Konsole: Module über eine Schnittstelle der Suite; „Alle aktualisieren“ mit Vorschau der betroffenen Instanzen.
- Installation: DNS-Prüfung erkennt Server hinter einem Router (NAT).

## Apps

- Ticketbearbeitung für die IT: Ansichten (Meine, Nicht zugewiesen, Überfällig, Warten auf Support, Warten auf Anwenderinfo), zuweisen an Person oder Gruppe, Status, Priorität, Kategorie, öffentliche Antwort oder interne Notiz mit Textbausteinen, lösen.
- Meldung im Namen eines Kollegen aufnehmen.
- Anleitungen aus der Wissensdatenbank direkt öffnen.
- Menügruppe „IT-Service/Helpdesk“.

## Android

- Anhänge im Ticketverlauf als Vorschau, zum Öffnen antippen.

## Server aktualisieren

Bestehende Installation (ab 0.1.0 legt der Installer das Skript an):

```bash
sudo /opt/estrichone/update.sh            # neueste Version
sudo /opt/estrichone/update.sh 1.0.15  # genau diese Version
```

Das Skript sichert vorher, aktualisiert, wartet auf alle Dienste und meldet Erfolg oder Fehler. Ältere Installationen
einmalig mit dem Installer-Befehl unten aktualisieren.

## Hosting-Konsole installieren

```bash
curl -fsSL https://raw.githubusercontent.com/florians25/EstrichONE/main/install.sh | sudo bash -s -- konsole
```

## Server neu installieren

```bash
curl -fsSL https://raw.githubusercontent.com/florians25/EstrichONE/main/install.sh | sudo bash -s -- --version 1.0.15
```

Gleichwertig mit vorhandenem Docker:

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:1.0.15
```

## Archivserver und Backup-Ziel (weitere Rechner)

```bash
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.15 archiv
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.15 backup-ziel
```

Aktualisieren: denselben Befehl mit der neuen Version erneut ausführen. Koppeln in EstrichONE unter System → Archiv
bzw. System → Backup-Ziele.
