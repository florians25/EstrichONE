# EstrichONE 0.1.4

## Neu
- **Auslagerung auf den Storage:** Wird der Platz auf dem Hauptserver knapp (Standard: unter 15 % frei), werden
  Original-Fotos, -Videos und -Dokumente verschlüsselt auf den gekoppelten Storage (Kombiserver, Port 8445)
  ausgelagert; optional zusätzlich nach Regeln (Alter, abgeschlossene Bauakten, Dateiarten). Vorschaubilder bleiben
  lokal, Originale werden beim Öffnen transparent nachgeladen. Lokal gelöscht wird erst nach geprüfter Übertragung
  und Sicherungskopie. Rückholen je Datei, Bauakte oder komplett. Seite: System › Speicher-Auslagerung.
  Bestehenden Kombiserver erweitern: Installer erneut mit `-e ESTRICHONE_OFFLOAD_DATA_DIR=…` (docs/backup.md › Auslagerung).

## Verbessert
- **Tagesübersicht** neu gestaltet: Tagesnavigation (Alt+←/→), anklickbare Kennzahlen, Zeitleiste je Kolonne,
  ruhige Karten für Lieferungen, Wiedervorlagen, Freigaben, Aufgaben, Tickets; Druck auf A4.
- **Verwaltung** übersichtlicher: fünf klare Gruppen, Übersichtsseite mit Suche, einheitliches Seitenmuster mit
  Statuszeile „Alles in Ordnung / Handlungsbedarf“, gefährliche Aktionen getrennt am Seitenende.
- Handbücher für Web und App werden an jedes Release angehängt.

## Aktualisieren
`sudo /opt/estrichone/update.sh 0.1.4`
