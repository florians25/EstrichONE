# EstrichONE 1.0.24


## Neu

- **Teams aus der Bauakte:** Im Teams-Menü der Bauakte gibt es nur noch „In Teams öffnen“, „Teams-Chat anlegen …“, „Per Link verknüpfen …“ und „Teams-Chat löschen …“.
- **Teilnehmer frei wählen:** Beim Anlegen ist das Bauakten-Team vorausgewählt, dazu lassen sich Kolonnen, Gruppen und einzelne Personen hinzufügen. Die Mitglieder werden automatisch abgeglichen.
- **Teams-Chat je Kolonne:** Unter Planung › Kolonnen hat jede Zeile den Knopf „Teams-Chat“, gelöscht wird im Menü „…“.
- **Zuverlässiger:** Bei langsamer Antwort von Microsoft entstehen keine doppelten Chats mehr, Fehlermeldungen sind verständlich auf Deutsch.

## Apps

- **Aufgeräumt:** Heute, Bauakte und Mehr sind ruhige Standardlisten.
- **Bauakte:** Die Basisdaten stehen oben auf einen Blick, „Foto“ und „Video“ sind unten immer direkt erreichbar, alles andere steht im Menü „…“.
- **Mehr:** Neuer Abschnitt „Service“ mit Urlaub, Helpdesk und „Problem melden“; der Teams-Chat der eigenen Kolonne steht ebenfalls hier.
- **Teams-Links öffnen immer die Teams-App** (fehlt sie, kommt ein Hinweis zum Installieren).

## Server aktualisieren

Bestehende Installation (ab 0.1.0 legt der Installer das Skript an):

```bash
sudo /opt/estrichone/update.sh            # neueste Version
sudo /opt/estrichone/update.sh 1.0.24  # genau diese Version
```

Das Skript kündigt das Update allen Benutzern eine Minute vorher an, meldet alle ab, sichert, aktualisiert, wartet auf
alle Dienste und gibt nach weiteren 30 Sekunden frei (mindestens 2,5 Minuten, deploy/README.md „Update-Ablauf“); es
meldet Erfolg oder Fehler. Ältere Installationen
einmalig mit dem Installer-Befehl unten aktualisieren.

## Server neu installieren

```bash
curl -fsSL https://raw.githubusercontent.com/florians25/EstrichONE/main/install.sh | sudo bash -s -- --version 1.0.24
```

Gleichwertig mit vorhandenem Docker:

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:1.0.24
```

## Archivserver und Backup-Ziel (weitere Rechner)

```bash
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.24 archiv
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.24 backup-ziel
```

Aktualisieren: denselben Befehl mit der neuen Version erneut ausführen. Koppeln in EstrichONE unter System → Archiv
bzw. System → Backup-Ziele.
