## Server installieren oder aktualisieren

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:0.1.0-preview.5
```

Betriebsart `proxy` (Standard): nur HTTP auf **8181**, HTTPS macht der Nginx Proxy Manager (Proxy Host → `http`,
Server-IP, `8181`, Let's Encrypt, „Force SSL“, unter Advanced `client_max_body_size 600m;`).
Betriebsart `direkt`: `-e ESTRICHONE_MODE=direkt` (HTTPS auf 8143). Bestehende Installationen: denselben Befehl mit
neuer Version ausführen – Daten bleiben erhalten.

## Hosting-Konsole (neu)

Verwaltet viele Kundeninstanzen auf einem Server: Mandanten anlegen und bereitstellen, starten/stoppen, aktualisieren
(mit Vorab-Sicherung), sperren, sichern, löschen; Status, Ressourcen, Sicherungen, Logs; **Ankündigungen und
Wartungsmodus** an Instanzen verteilen; Anmeldung mit 2FA; alle OpenUI5-Themes. Installation und Bedienung:
`hosting/README.md` im Server-Paket bzw. im Repository.

```bash
sudo docker run --rm -it -v /var/run/docker.sock:/var/run/docker.sock \
  ghcr.io/florians25/estrichone-hosting:0.1.0-preview.5 install
```

## Weboberfläche (OpenUI5, neu aufgebaut)

- Alle OpenUI5-Themes wählbar (Einstellungen), „Systemeinstellung folgen“; eigenes Logo; als App installierbar
  (Edge/Chrome → „Als App installieren“).
- Bauakte als Objektseite: Übersicht mit Freigaben und neuesten Dokumenten, **Dokumente** (Ordner, Mehrfach-Upload,
  Fassungen, ZIP, Freigaben), **Fotos/Videos**, **Dokumentation** (Bautagebuch, Prüfungen), **Verlauf** mit
  Feldänderungen und „Angelegt von“.
- Geführte **Assistenten** für Bauakten-Anlage (Kunde Pflicht, Dublettenprüfung) und Erstbegehung.
- **Zentrale Dokumentenverwaltung** (`Dokumente`): Ordner je Dokumentart, Suche, Freigabeprozess, „Warten auf
  Genehmigung“ im Dashboard.
- **PDF**: Bauaktenbericht mit Fotos, Kolonneneinteilung für Tag und Woche.
- **Plantafel** wie ein Dienstplan (Kolonnen/Mitarbeiter, Tag/Woche/Monat, Ziehen, Abwesenheiten, Konflikte, Vorrat).
- **Rollen mit Rechtematrix**, Stammdaten (Textbausteine, Ordnervorlagen, Bauakten-Vorlagen).
- Ankündigungen als Banner, Wartungsseite.

## Bekannte Grenzen

- Weboberfläche: Zwischenstand, Feinschliff folgt bis 0.1.0.
- iOS: Scanner-Kamera, Texterkennung echter Scans und Videoaufnahme sind nur auf echten Geräten prüfbar (im Simulator
  getestet sind PDF-Erzeugung und Abläufe).
- Hosting: Benutzer- und Speichergrenzen eines Tarifs werden angezeigt, aber noch nicht erzwungen (RAM/CPU schon).
- Docker-Images nur für x86-64.
