# EstrichONE 1.0.32


## Neu

- **Chat:** Dateien und Fotos tauschen Sie über Microsoft Teams aus. Im Chat erscheint ein entsprechender Hinweis mit „In Teams öffnen“, sofern Teams verbunden ist. Nachrichten und Standort laufen weiter über EstrichONE. Bereits gesendete Anhänge bleiben sichtbar.
- Anhänge im EstrichONE-Chat sind ab dieser Version standardmäßig ausgeschaltet. Unter Verwaltung › Systemeinstellungen im Abschnitt Chat lassen sie sich bei Bedarf wieder erlauben.
- **Bauakte:** Häufig genutzte Freitexte wie Hinweise, Zugang und Beschreibung stehen in der Übersicht als gut lesbare Textblöcke. Zeilenumbrüche bleiben erhalten, Telefonnummern, E-Mail-Adressen und Links sind anklickbar, lange Texte lassen sich mit „Mehr anzeigen“ aufklappen. Die Eingabefelder sind größer.

## Apps

- **Chat direkt erreichbar:** Der Chat hat einen eigenen Eintrag in der unteren Leiste mit der Zahl der ungelesenen Nachrichten. Eine Chat-Mitteilung öffnet sich direkt dort.
- **Erfassen nur in der Bauakte:** Der Eintrag „Erfassen“ in der unteren Leiste entfällt. In der Bauakte stehen unten „Foto“ und „Erfassen“ mit Video, Scan, Bautagebuch, Mangel, Aufgabe, Notiz, Erstbegehung, CM-Messung und Abnahme.
- **Heute mit mehr Informationen:** Auf dem iPhone fasst „Ihr Tag“ Einsätze, Beginn, Fläche, Kolonne, Fahrzeuge und Abwesende zusammen. Je Einsatz zeigt die Karte zusätzlich Leistung, Zugang, angeheftete Notizen, den Hinweis der Disposition und die letzte Nachricht im Chat der Baustelle. Genehmiger sehen offene Anträge.
- **Bauakte übersichtlicher:** Kopf mit Leistung, Kennzahlen und Sprungmarken. Hinweise zur Baustelle stehen als gut lesbare Textblöcke mit antippbaren Telefonnummern und Links.
- **Chat:** Hinweis, dass Dateien und Fotos über Microsoft Teams ausgetauscht werden. Nachrichten, Diktat und Standort laufen weiter über EstrichONE.
- Schaltflächen etwas kompakter, weiterhin gut mit Handschuhen bedienbar.

## Server aktualisieren

Bestehende Installation (ab 0.1.0 legt der Installer das Skript an):

```bash
sudo /opt/estrichone/update.sh            # neueste Version
sudo /opt/estrichone/update.sh 1.0.32  # genau diese Version
```

Das Skript kündigt das Update allen Benutzern eine Minute vorher an, meldet alle ab, sichert, aktualisiert, wartet auf
alle Dienste und gibt nach weiteren 30 Sekunden frei (mindestens 2,5 Minuten, deploy/README.md „Update-Ablauf“); es
meldet Erfolg oder Fehler. Ältere Installationen
einmalig mit dem Installer-Befehl unten aktualisieren.

## Server neu installieren

```bash
curl -fsSL https://raw.githubusercontent.com/florians25/EstrichONE/main/install.sh | sudo bash -s -- --version 1.0.32
```

Gleichwertig mit vorhandenem Docker:

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:1.0.32
```

## Archivserver und Backup-Ziel (weitere Rechner)

```bash
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.32 archiv
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.32 backup-ziel
```

Aktualisieren: denselben Befehl mit der neuen Version erneut ausführen. Koppeln in EstrichONE unter System → Archiv
bzw. System → Backup-Ziele.
