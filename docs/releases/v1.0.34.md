# EstrichONE 1.0.34



## Apps

Die Apps für iPhone, iPad und Android sind grundlegend überarbeitet und folgen auf beiden Plattformen demselben Aufbau.

- **Heute neu aufgebaut:** Oben steht Ihr Tag auf einen Blick mit Einsätzen, Beginn und offenen Aufgaben. Darunter folgt der laufende bzw. nächste Einsatz als Hauptkarte mit Leistung, Kolonne, Fahrzeug, Ansprechpartner und Zugangshinweis sowie den Schaltflächen Route, Anrufen, Chat und Bauakte. Danach weitere Einsätze, Aufgaben und Freigaben sowie Morgen.
- **Mitteilungen kompakt:** Mitteilungen der Verwaltung stehen in einer Zeile, Störungen rot hervorgehoben. Ein Tippen zeigt alle mit Details.
- **Baustellen übersichtlicher:** Filter wie Heute und Laufend, heute eingeplante Baustellen zuerst, jede Zeile mit farbigem Status und nächstem Termin.
- **Bauakte nach dem Arbeitsablauf:** Kopf mit Status, Adresse und Aktionsleiste (Route, Anrufen mit Auswahl des Kontakts, Chat, Teams). Danach der heutige bzw. nächste Termin, Hinweise zur Baustelle, Leistung und Kennwerte, der Ablauf von der Erstbegehung über Einbringen und Belegreife bis zur Abnahme mit direktem Erfassen des nächsten Schritts, offene Aufgaben und Mängel, Fotos und Dokumentation, Kontakte sowie Beschreibung und Verlauf.
- **Erfassen verdeckt nichts mehr:** Auf dem iPhone über „+“ oben rechts, auf Android über die Schaltfläche unten rechts, die beim Scrollen einklappt.
- **Einheitliches Erscheinungsbild:** kompakte Kopfzeilen, einheitliche Statusfarben, ruhigere Listen in Chat und Kunden, Ziehen zum Aktualisieren.

## Server aktualisieren

Bestehende Installation (ab 0.1.0 legt der Installer das Skript an):

```bash
sudo /opt/estrichone/update.sh            # neueste Version
sudo /opt/estrichone/update.sh 1.0.34  # genau diese Version
```

Das Skript kündigt das Update allen Benutzern eine Minute vorher an, meldet alle ab, sichert, aktualisiert, wartet auf
alle Dienste und gibt nach weiteren 30 Sekunden frei (mindestens 2,5 Minuten, deploy/README.md „Update-Ablauf“); es
meldet Erfolg oder Fehler. Ältere Installationen
einmalig mit dem Installer-Befehl unten aktualisieren.

## Server neu installieren

```bash
curl -fsSL https://raw.githubusercontent.com/florians25/EstrichONE/main/install.sh | sudo bash -s -- --version 1.0.34
```

Gleichwertig mit vorhandenem Docker:

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:1.0.34
```

## Archivserver und Backup-Ziel (weitere Rechner)

```bash
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.34 archiv
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.34 backup-ziel
```

Aktualisieren: denselben Befehl mit der neuen Version erneut ausführen. Koppeln in EstrichONE unter System → Archiv
bzw. System → Backup-Ziele.
