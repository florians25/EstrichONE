# EstrichONE 1.0.41



## Neu

- **Prüfung vor dem Anlegen eines Kunden:** Beim Klick auf „Kunde anlegen“ prüft EstrichONE zuerst in Lexware Office, ob es den Kunden dort schon gibt, und legt ihn erst danach an. Gibt es ihn schon, übernehmen Sie ihn aus Lexware Office oder legen ihn bewusst neu an. Die Prüfung gilt im Web an jeder Stelle, an der ein Kunde neu entsteht, und in den Apps beim Sichern eines neuen Kunden.
- **Lexware Office nicht erreichbar:** Ist die Prüfung nicht möglich, wird der Kunde nicht stillschweigend angelegt. EstrichONE fragt nach, ob Sie ihn ohne Prüfung anlegen möchten.
- **Kopf der Bauakte:** „Hinweise und Zugang“ erscheint nicht mehr als Hinweis im Kopf der Bauakte, sondern nur noch im eigenen Feld der Übersicht.

## Apps

- **Lexware Office in der Bauakte:** Ist der Kunde einer Bauakte mit Lexware Office verknüpft, zeigt die Bauakte auf iPhone, iPad und Android den Kontakt aus Lexware Office, den Stand des Abgleichs und die zugeordneten Rechnungen und Angebote. Ein Tipp auf einen Beleg öffnet das PDF. Für Entwürfe stellt Lexware Office kein PDF bereit.
- **Neuer Kunde:** Die Apps melden „Achtung: Dieser Kunde ist bereits in Lexware Office vorhanden.“ und bieten die Übernahme aus Lexware Office an.
- **Ohne Verbindung angelegte Kunden:** Der Server prüft sie nach der Synchronisation. Ohne ähnlichen Kontakt werden sie in Lexware Office angelegt, sonst stehen sie im Kundenabgleich unter „Mögliche Dubletten“.

## Server aktualisieren

Bestehende Installation (ab 0.1.0 legt der Installer das Skript an):

```bash
sudo /opt/estrichone/update.sh            # neueste Version
sudo /opt/estrichone/update.sh 1.0.41  # genau diese Version
```

Das Skript kündigt das Update allen Benutzern eine Minute vorher an, meldet alle ab, sichert, aktualisiert, wartet auf
alle Dienste und gibt nach weiteren 30 Sekunden frei (mindestens 2,5 Minuten, deploy/README.md „Update-Ablauf“); es
meldet Erfolg oder Fehler. Ältere Installationen
einmalig mit dem Installer-Befehl unten aktualisieren.

## Server neu installieren

```bash
curl -fsSL https://raw.githubusercontent.com/florians25/EstrichONE/main/install.sh | sudo bash -s -- --version 1.0.41
```

Gleichwertig mit vorhandenem Docker:

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:1.0.41
```

## Archivserver und Backup-Ziel (weitere Rechner)

```bash
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.41 archiv
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.41 backup-ziel
```

Aktualisieren: denselben Befehl mit der neuen Version erneut ausführen. Koppeln in EstrichONE unter System → Archiv
bzw. System → Backup-Ziele.
