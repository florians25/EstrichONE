# EstrichONE 1.0.17

## Neu

- Microsoft Teams als Ort für Unterhaltungen: Einrichtung unter Einstellungen › Integrationen › Microsoft Teams (eigene Entra-App des Betriebs), je Bauakte Kanal im Team „Baustellen“, Gruppenchat oder Verknüpfung per Link, Knopf „In Teams öffnen“, Mitgliederabgleich und Ereigniskarten (Mangel, Abnahme, Termine, Einsatzplan). Chat-Modus „EstrichONE-Chat“ / „Microsoft Teams“ / „beides“; im Teams-Modus bleibt der bisherige Chat als Archiv lesbar und exportierbar. Anleitung: Handbuch Kapitel 9.
- Bauakte › Dokumentation: eigener Reiter „Erstbegehung“ mit Status, Termin aus der Planung, Durchführen, Protokollen, Fotos und PDFs; der bisherige Reiter heißt „CM-Messungen“.
- Bauakte › Kontakte: kompakter Leerzustand; „Team im Betrieb“ als Karten mit Knopf „Mitarbeiter zuweisen“.
- Seitenkopf auf allen Seiten als gerundete Karte, bündig mit dem Inhalt, rechts nichts mehr abgeschnitten.

## Apps

- Neuer Bereich „Erstbegehung“ in der Bauakte (Status, Termin, Durchführen, Protokolle, Fotos).
- „In Teams öffnen“ in Bauakte, Heute und Mehr; im Teams-Modus ist der Chat ein Archiv.

## Server aktualisieren

Bestehende Installation (ab 0.1.0 legt der Installer das Skript an):

```bash
sudo /opt/estrichone/update.sh            # neueste Version
sudo /opt/estrichone/update.sh 1.0.17  # genau diese Version
```

Das Skript kündigt das Update allen Benutzern eine Minute vorher an, meldet alle ab, sichert, aktualisiert, wartet auf
alle Dienste und gibt nach einer weiteren Minute frei (mindestens 3 Minuten, deploy/README.md „Update-Ablauf“); es
meldet Erfolg oder Fehler. Ältere Installationen
einmalig mit dem Installer-Befehl unten aktualisieren.

## Server neu installieren

```bash
curl -fsSL https://raw.githubusercontent.com/florians25/EstrichONE/main/install.sh | sudo bash -s -- --version 1.0.17
```

Gleichwertig mit vorhandenem Docker:

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:1.0.17
```

## Archivserver und Backup-Ziel (weitere Rechner)

```bash
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.17 archiv
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.17 backup-ziel
```

Aktualisieren: denselben Befehl mit der neuen Version erneut ausführen. Koppeln in EstrichONE unter System → Archiv
bzw. System → Backup-Ziele.
