# EstrichONE 1.0.8

## Neu

- **App – Benachrichtigungen neu (iPhone, iPad, Android):** gruppiert nach Heute/Gestern/Diese Woche/Älter oder nach Art,
  kompakte Zeilen mit Ungelesen-Punkt und farbigem Symbol, Filter (Alle, Ungelesen, je Art), Suche, Wischen für
  gelesen/ungelesen und Löschen, „Alle als gelesen“, Ältere laden, Einzelansicht. Tippen öffnet direkt das Ziel.
  Mitteilungseinstellungen direkt erreichbar.
- **App – Videos teilen:** Videos direkt aus der App teilen (z. B. WhatsApp, Mail, AirDrop) als echte Videodatei.
  Android zusätzlich Mehrfachauswahl im Foto-Raster.
- **Web – Bauakten-Kopf:** Die Fläche kommt jetzt aus den Basisdaten (Gesamtfläche); nur wenn dort nichts steht,
  wird die Summe der Räume angezeigt.

## Update

```bash
sudo /opt/estrichone/update.sh 1.0.8
```
