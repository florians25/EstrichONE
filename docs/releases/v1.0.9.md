# EstrichONE 1.0.9

## Verbessert

- **Texte sachlich überarbeitet** in Server, Web, iPhone- und Android-App: Pushnachrichten, Statushinweise,
  E-Mail-Vorlagen, Fehlermeldungen, Dialoge und leere Zustände.
- **Pushnachrichten nach festem Schema:** Titel nennt das Ereignis, Text das Objekt und die wesentliche Angabe,
  z. B. „Einsatzplan freigegeben“ / „Mo 10.11. · 7:00 Uhr · BV Müller“. Ohne Emojis und Ausrufezeichen.
  Übersicht aller Texte: `docs/benachrichtigungen.md`.
- **Statushinweise:** „Backup-Ziel nicht erreichbar. Letzte erfolgreiche Sicherung: …“ statt „ACHTUNG: …“.
- **E-Mails:** „Guten Tag …“ / „Mit freundlichen Grüßen“.

## Update

```bash
sudo /opt/estrichone/update.sh 1.0.9
```
