# EstrichONE 1.0.43



## Neu

- **Fehler aus Lexware Office verständlich:** Lehnt Lexware Office einen Beleg ab, nennt EstrichONE den Grund auf Deutsch und bietet die Behebung direkt an. Der Originaltext steht unter „Technische Einzelheiten“.
- **Steuerart § 13b:** Lässt Lexware Office die Bauleistung nach § 13b UStG für Ihr Unternehmen nicht zu, übernehmen Sie mit „Steuerart Netto übernehmen und erneut senden“ die Steuerart Netto. EstrichONE merkt sich die erlaubten Steuerarten. In den Lexware-Einstellungen prüfen Sie sie erneut.
- **Status je Belegart:** Auftragsbestätigungen und Lieferscheine zeigen „Erstellt“ statt „Offen“ und zählen nicht zu den offenen Beträgen. Lieferscheine erscheinen als eigene Belegart.
- **Bauakte:** Die Angaben aus Lexware Office stehen in der Übersicht ganz unten.
- **PDF-Berichte:** Alle Berichte zeigen das Firmenlogo aus den Einstellungen. Fotos aus der Bauakte erscheinen wieder im PDF, richtig ausgerichtet und mit Bildunterschrift. Videos sind als Hinweis aufgeführt.
- **Verwaltung:** Die Symbole der Übersicht erscheinen in allen Farbschemata.

## Apps

- **Bauakte:** Neuer Schnellzugriff unter dem Kopf: Basisdaten, Beschreibung, Hinweise und Zugang, Fotos und Videos, Dokumente, Kontakte, Lexware. Die Abschnitte folgen dieser Reihenfolge, Lexware Office steht am Ende.
- **Lexware Office:** Die Zusammenfassung der Belege entfällt, die Liste der Belege bleibt. Auftragsbestätigungen und Lieferscheine zeigen „Erstellt“.

## Server aktualisieren

Bestehende Installation (ab 0.1.0 legt der Installer das Skript an):

```bash
sudo /opt/estrichone/update.sh            # neueste Version
sudo /opt/estrichone/update.sh 1.0.43  # genau diese Version
```

Das Skript kündigt das Update allen Benutzern eine Minute vorher an, meldet alle ab, sichert, aktualisiert, wartet auf
alle Dienste und gibt nach weiteren 30 Sekunden frei (mindestens 2,5 Minuten, deploy/README.md „Update-Ablauf“); es
meldet Erfolg oder Fehler. Ältere Installationen
einmalig mit dem Installer-Befehl unten aktualisieren.

## Server neu installieren

```bash
curl -fsSL https://raw.githubusercontent.com/florians25/EstrichONE/main/install.sh | sudo bash -s -- --version 1.0.43
```

Gleichwertig mit vorhandenem Docker:

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:1.0.43
```

## Archivserver und Backup-Ziel (weitere Rechner)

```bash
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.43 archiv
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.43 backup-ziel
```

Aktualisieren: denselben Befehl mit der neuen Version erneut ausführen. Koppeln in EstrichONE unter System → Archiv
bzw. System → Backup-Ziele.
