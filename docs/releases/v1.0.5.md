# EstrichONE 1.0.5

## Neu

- **Fehler melden / Funktion wünschen:** Jeder Benutzer kann im WebPortal über ein geführtes Formular einen Fehler
  melden oder eine neue Funktion wünschen (Art → Angaben → Anhänge → Prüfen → Bestätigung). Die aktuelle Seite wird
  automatisch mitgeschickt.
  - Schnellzugriff: Button in der Kopfleiste direkt links neben dem Profil (in schmalen Fenstern im „…“-Menü),
    außerdem im Benutzermenü.
  - „Meine Meldungen“ (Seitenleiste unten und Benutzermenü): Status, Antworten der IT, Rückfragen beantworten.
  - Nummern im Format F-JJJJ-NNNN.
- **IT-Center → Fehler & Wünsche:** Die IT sieht alle Meldungen mit Filtern (Art, Status, Bereich, Priorität, Suche),
  setzt Status und Priorität, antwortet oder schreibt interne Notizen.
  - Neues Recht „Meldungen verwalten“ (`feedback.manage`); bestehende Rollen mit Helpdesk-Recht bekommen es automatisch.
  - Benachrichtigungen: neue Meldung an die IT, Statuswechsel und Antwort an den Einreicher.
- Behoben: „Einstellungen“ in der Seitenleiste unten reagierte nicht.

## Update

```bash
sudo /opt/estrichone/update.sh 1.0.5
```
