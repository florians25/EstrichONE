# EstrichONE 0.1.0-preview.22

## Backup, Archiv, Notfall
- Täglich eine Vollsicherung (zusätzlich inkrementell möglich), Zeitplan und Aufbewahrung in den Einstellungen; Inhalt:
  Datenbank, Fotos, Dokumente, Videos, Schlüssel, Konfiguration. Sonntags Prüfung und Probe-Wiederherstellung.
- Topologien: Server im Rechenzentrum + Backup-Ziel zuhause hinter NAT („Ziel zieht“, verbindet sich ausgehend) oder
  umgekehrt (Kopplung per Code). Anleitung mit Diagrammen in docs/backup.md.
- Backup Center: Sicherungen, Zeitplan/Meldungen, Notfall; „Wiederherstellen“ für das ganze System (mit Sperre und
  Fortschritt, alte Datenbank bleibt erhalten) oder einzelne Dateien.
- Worst Case: Neuinstallation aus der Sicherung mit einem Befehl (`… estrichone-installer:<version> restore`) und
  Notfallblatt (PDF) zum Ausdrucken.
- Warnungen überall (Web und App), nur wenn eingerichtet: ROT bei Ausfall des Backup-Servers, GELB bei Ausfall des
  Archiv-Servers. Admins bekommen nach jeder Sicherung eine Pushnachricht (abschaltbar).
- Wartungsmodus sperrt jetzt auch die App (nicht übertragene Daten bleiben erhalten); Störungsseite, wenn der Server
  nicht erreichbar ist.

## Web
- „Wer fährt wohin“ aus dem Web entfernt (bleibt in der App; alte Links öffnen die Tagesansicht des Cockpits).
- Chat-Modul (Büro ↔ Mitarbeiter, nur Text, Einzel- und Gruppenchats, auch je Kolonne): verschlüsselt gespeichert,
  Löschfrist einstellbar, Export/Löschung je Person. Standardmäßig aus – einschalten unter Systemeinstellungen → Module.
- Mehr Benachrichtigungen (Zuweisungen, Notizen, Abnahme, Urlaub, Wartung, Backup), je Benutzer abbestellbar.

## iOS
- Rote/gelbe Backup-/Archiv-Hinweise, Sperrbildschirm im Wartungsmodus.
- „Nur Ansicht“ nach 5 Minuten ohne Serververbindung (mit „Trotzdem arbeiten“ auf eigene Gefahr).
- Chat in Messenger-Optik, Benachrichtigungsarten einstellbar.

## Aktualisieren
`sudo /opt/estrichone/update.sh 0.1.0-preview.22`
