# EstrichONE 1.0.36



## Apps

- **Disposition auf Android:** Planer weisen Baustellen zu, verschieben Einsätze, ändern Uhrzeit und Reihenfolge, tauschen Mitarbeiter, Fahrzeuge und Kolonnen und geben den Plan frei. Ohne Verbindung werden Änderungen vorgemerkt.
- **Disposition schneller erreichbar:** Auf Heute steht für Planer direkt unter den Mitteilungen „Disposition heute“ mit dem Stand des Tages. Im Menü Mehr gibt es den Abschnitt „Planung“.
- **iPhone und iPad:** Jeder Einsatz in der Disposition hat ein sichtbares Menü. „Uhrzeit ändern“ öffnet nur Beginn und Ende, ein Tippen auf den Einsatz öffnet die Bauakte.

## Server aktualisieren

Bestehende Installation (ab 0.1.0 legt der Installer das Skript an):

```bash
sudo /opt/estrichone/update.sh            # neueste Version
sudo /opt/estrichone/update.sh 1.0.36  # genau diese Version
```

Das Skript kündigt das Update allen Benutzern eine Minute vorher an, meldet alle ab, sichert, aktualisiert, wartet auf
alle Dienste und gibt nach weiteren 30 Sekunden frei (mindestens 2,5 Minuten, deploy/README.md „Update-Ablauf“); es
meldet Erfolg oder Fehler. Ältere Installationen
einmalig mit dem Installer-Befehl unten aktualisieren.

## Server neu installieren

```bash
curl -fsSL https://raw.githubusercontent.com/florians25/EstrichONE/main/install.sh | sudo bash -s -- --version 1.0.36
```

Gleichwertig mit vorhandenem Docker:

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:1.0.36
```

## Archivserver und Backup-Ziel (weitere Rechner)

```bash
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.36 archiv
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.36 backup-ziel
```

Aktualisieren: denselben Befehl mit der neuen Version erneut ausführen. Koppeln in EstrichONE unter System → Archiv
bzw. System → Backup-Ziele.
