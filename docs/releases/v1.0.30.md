# EstrichONE 1.0.30


## Neu

- Web: Klarere Seitennavigation. Oben stehen nur noch die Fachgruppen Auftragsbearbeitung, Planung, Material, Büro und Personal. Unten fest: **IT-Service/Helpdesk** (Helpdesk, Problem melden, Wissensdatenbank, Meine Fehler & Wünsche) und – für die Administration – **Verwaltung** mit Übersicht und Suche über alle Verwaltungsbereiche.
- Verwaltungsseiten zeigen über dem Titel „Verwaltung / …“ mit Rücksprung zur Übersicht.
- Kolonnen sowie Geräte & Fahrzeuge stehen jetzt unter **Planung**.
- Einheitliche Namen: „Planungs-Cockpit“ (vorher Disponenten-Cockpit), „Mein Urlaub“, „Meine Fehler & Wünsche“; Menüeinträge und Reiter heißen gleich.
- Benutzermenü geordnet nach Mein Konto, Hilfe und Abmelden; Tooltips an allen Navigationseinträgen.
- Alle bisherigen Adressen und Lesezeichen funktionieren weiter.

## Server aktualisieren

Bestehende Installation (ab 0.1.0 legt der Installer das Skript an):

```bash
sudo /opt/estrichone/update.sh            # neueste Version
sudo /opt/estrichone/update.sh 1.0.30  # genau diese Version
```

Das Skript kündigt das Update allen Benutzern eine Minute vorher an, meldet alle ab, sichert, aktualisiert, wartet auf
alle Dienste und gibt nach weiteren 30 Sekunden frei (mindestens 2,5 Minuten, deploy/README.md „Update-Ablauf“); es
meldet Erfolg oder Fehler. Ältere Installationen
einmalig mit dem Installer-Befehl unten aktualisieren.

## Server neu installieren

```bash
curl -fsSL https://raw.githubusercontent.com/florians25/EstrichONE/main/install.sh | sudo bash -s -- --version 1.0.30
```

Gleichwertig mit vorhandenem Docker:

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:1.0.30
```

## Archivserver und Backup-Ziel (weitere Rechner)

```bash
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.30 archiv
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:1.0.30 backup-ziel
```

Aktualisieren: denselben Befehl mit der neuen Version erneut ausführen. Koppeln in EstrichONE unter System → Archiv
bzw. System → Backup-Ziele.
