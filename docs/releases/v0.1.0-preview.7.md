## Neu und behoben

**Fehlerbehebungen**
- Foto-/Datei-Upload hinter Nginx Proxy Manager: Upload in 4-MB-Teilen mit Wiederholung und Fortsetzen, klare
  Fehlerursache statt „Server nicht erreichbar“.
- Karte: OpenStreetMap blockiert die Kacheln nicht mehr; Kartenserver einstellbar.
- Sitzungen: kein Abmelden mehr nach 10 Minuten. 12 Stunden Leerlauf bzw. 30 Tage mit „Angemeldet bleiben“
  (einstellbar); bei Ablauf Anmeldedialog über der Seite ohne Datenverlust.
- Anmeldung hinter einem Proxy: kein Sperren durch die Anmeldebremse mehr, wenn viele Benutzer dieselbe Adresse haben.
- Sync: Lücken werden geschlossen, abgelehnte Vorgänge wiederholt; eingeplante Mitarbeiter sehen ihre Bauakte
  („Daten nicht verfügbar“ behoben); „Mir zuweisen“ in der App.

**Web**
- Einstellungen der Installation (Sitzung, Karte, Nummernkreise, Bauakte, Freigaben, Benachrichtigungen, PDF …).
- Erstbegehung mit freien Notizen (auch im PDF).
- System → Archiv, Backup-Ziele, E-Mail (siehe unten).

**Planung, Personal, Helpdesk (Server)**
- „Wer fährt wohin“ je Tag mit Schnellplanung und PDF, Terminkalender, Verschieben im Teamplaner.
- Personalverwaltung: Urlaubsanträge mit Genehmigung und Resturlaub, Urlaubsplan, Krankmeldungen, Fristen.
- Helpdesk mit Verlauf und E-Mail bei Änderungen.

**iOS**
- Startseite mit „Wer fährt wohin“ und offenen Aufgaben; Schnellplanung (iPad per Ziehen).
- Bauakte: Status ändern und stornieren (offline), „Mir zuweisen“.
- Erstbegehung mit Fotos je Prüfpunkt, Unterschrift, freien Notizen, Protokoll und PDF; direkt nach der Anlage startbar.
- iPad zweispaltig, Ticketverlauf, zuverlässigerer Sync mit Upload-Fortschritt.

**Betrieb**
- `update.sh`: Ab dieser Version legt der Installer `/opt/estrichone/update.sh` an – künftig genügt
  `sudo /opt/estrichone/update.sh`.
- Archivserver (10 Jahre, unveränderbar, Löschsperre, Prüfprotokoll, Prüfer-Export) und Backup-Ziel (nur anhängen) auf
  eigener Hardware, je mit einem Befehl installiert und per Code gekoppelt.
- E-Mail-Konto (SMTP) mit Testmail, Vorlagen und Versandprotokoll.

## Server aktualisieren / installieren

```bash
sudo docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /opt/estrichone:/opt/estrichone \
  ghcr.io/florians25/estrichone-installer:0.1.0-preview.7
```

Danach für künftige Updates: `sudo /opt/estrichone/update.sh`

## Archivserver und Backup-Ziel (weitere Rechner)

```bash
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:0.1.0-preview.7 archiv
sudo docker run --rm -v /var/run/docker.sock:/var/run/docker.sock ghcr.io/florians25/estrichone-installer:0.1.0-preview.7 backup-ziel
```

Koppeln in EstrichONE unter System → Archiv bzw. System → Backup-Ziele (Adresse und angezeigten Code eingeben).

## Hosting-Konsole

sudo docker run --rm -it -v /var/run/docker.sock:/var/run/docker.sock \
