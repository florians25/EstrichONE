# Tastaturkürzel der Weboberfläche

## Überall

| Tasten | Wirkung |
|---|---|
| <kbd>Alt</kbd> + <kbd>N</kbd> | Neue Bauakte (Assistent) |
| <kbd>Strg</kbd> + <kbd>Enter</kbd> | Formular bzw. Dialog speichern (Tagesbericht, Notiz, Telefon-Schnellerfassung, Helpdesk-Antwort) |
| <kbd>Esc</kbd> | Dialog oder Auswahlliste schließen |
| <kbd>Enter</kbd> im Suchfeld | Alle Treffer in der Bauaktenliste |
| <kbd>Strg</kbd> + Klick auf Link | Seite in neuem Tab |
| <kbd>Tab</kbd> / <kbd>Umschalt</kbd> + <kbd>Tab</kbd> | Nächstes / vorheriges Feld |

## Vorschau und Großansicht

| Tasten | Wirkung |
|---|---|
| <kbd>←</kbd> / <kbd>→</kbd> | Vorheriges / nächstes Foto bzw. Dokument |
| <kbd>Esc</kbd> | Vorschau schließen |

## Tagesübersicht

| Tasten | Wirkung |
|---|---|
| <kbd>Alt</kbd> + <kbd>←</kbd> / <kbd>→</kbd> | Einen Tag zurück / vor |

## Helpdesk

| Tasten | Wirkung |
|---|---|
| <kbd>Strg</kbd> + <kbd>V</kbd> im Antwortfeld | Bildschirmfoto anhängen |
| <kbd>Strg</kbd> + <kbd>Enter</kbd> | Antwort senden |

## Disponenten-Cockpit

| Tasten | Wirkung |
|---|---|
| <kbd>?</kbd> | Hilfe zur Bedienung |
| <kbd>Enter</kbd> | Markierten Einsatz bearbeiten |
| <kbd>Leertaste</kbd> | Einsatz zur Auswahl hinzufügen / entfernen |
| <kbd>Strg</kbd> + Klick | Mehrfachauswahl |
| <kbd>Alt</kbd> + <kbd>←</kbd> / <kbd>→</kbd> | Auswahl einen Tag früher / später |
| <kbd>N</kbd> | Auswahl auf den nächsten freien Tag |
| <kbd>Entf</kbd> | Auswahl entfernen |
| <kbd>Esc</kbd> | Auswahl aufheben, Ziehen abbrechen |
| <kbd>Strg</kbd> + <kbd>Z</kbd> / <kbd>Y</kbd> | Rückgängig / Wiederholen |
| <kbd>Strg</kbd> + Ziehen | Einsatz kopieren statt verschieben |
| <kbd>T</kbd> | Zu heute |
| <kbd>W</kbd> | Wochenende ein / aus |
| <kbd>Bild ↑</kbd> / <kbd>Bild ↓</kbd> | Vorheriger / nächster Zeitraum |
| <kbd>Umschalt</kbd> + <kbd>F10</kbd> | Kontextmenü |

## Menüs im Cockpit

| Tasten | Wirkung |
|---|---|
| <kbd>↑</kbd> / <kbd>↓</kbd> | Eintrag wählen |
| <kbd>Enter</kbd>, <kbd>Leertaste</kbd>, <kbd>→</kbd> | Öffnen |
| <kbd>Esc</kbd>, <kbd>←</kbd> | Schließen |

In der **Kolonnenplanung** öffnen <kbd>Enter</kbd> oder <kbd>Leertaste</kbd> den markierten Einsatz. Auf dem Mac
entspricht <kbd>Strg</kbd> meist <kbd>⌘</kbd>.
